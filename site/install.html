    Download a package Files .deb, .rpm, .tar.gz
Package managers

Install from the command line

Each channel is updated with every release, so your usual upgrade command keeps Postino up to date.

Debian and Ubuntu apt

Add the signing key and the repository once, then install.

$ sudo curl -fsSLo /etc/apt/keyrings/postino.asc https://postino.tanis.codes/postino.asc
$ echo "deb [signed-by=/etc/apt/keyrings/postino.asc] https://postino.tanis.codes/apt stable main" \
    | sudo tee /etc/apt/sources.list.d/postino.list
$ sudo apt update && sudo apt install postino

Fedora and openSUSE dnf, zypper

Add the repository once, then install. The key is imported on the first install.

# Fedora
$ sudo curl -fsSLo /etc/yum.repos.d/postino.repo https://postino.tanis.codes/rpm/postino.repo
$ sudo dnf install postino

# openSUSE
$ sudo zypper addrepo https://postino.tanis.codes/rpm/postino.repo
$ sudo zypper install postino

Arch Linux AUR

The AUR package is coming soon. Until then, install the tarball or build the package from a checkout.

$ git clone https://github.com/tanisperez/postino.git
$ cd postino/packaging/aur && makepkg -si

macOS Homebrew

Postino updates itself after the first install.

$ brew install --cask tanisperez/postino/postino

Windows winget

From a terminal. winget upgrade picks up new versions too.

> winget install Postino
First launch

A note on unsigned builds

Postino is not code signed yet, so your system asks once before opening it. Updates are not affected.

macOS

If macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once:

$ xattr -dr com.apple.quarantine /Applications/Postino.app

Windows

If SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Build from source

Postino builds with the stable Rust toolchain. Clone the repository and run cargo run --release. See the README for the system libraries each platform needs.
