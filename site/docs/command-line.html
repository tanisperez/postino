Docs / Reference

Command line

Postino is a desktop app, but it can be started from a terminal to open a given folder or request, and a few environment variables change how it starts.

Usage

$ postino [PATH]

The binary is postino on Linux (installed to /usr/bin by the packages), postino.exe in %LOCALAPPDATA%\Programs\Postino on Windows, and /Applications/Postino.app/Contents/MacOS/postino on macOS.

PATH isPostino opens
MissingThe last workspace you used, if the folder still exists.
A folderThat folder as the workspace.
A .postino fileThe remembered workspace if it contains the file, otherwise the file's folder, and then the file in a tab.
A path that does not existAn error saying the workspace could not be opened.
 
# Open the requests that live in a repository
$ postino ~/code/shop/api-requests

# Open one request
$ postino ~/code/shop/api-requests/orders/create.postino

Only the first argument is read. Postino is not single instance: running it again, or double clicking a .postino file while it runs, starts a second window process.

Environment variables

VariableEffect
POSTINO_LOGThe log level for this run: off, error, warn, info, debug or trace. Overrides the setting.
POSTINO_ENVThe name of an environment (a file name under environments/, without .env) to activate at startup.
POSTINO_AUTOSENDThe workspace-relative path of a request, such as auth/login.postino, to open and send right away.
HTTPS_PROXY, HTTP_PROXY, ALL_PROXY, NO_PROXYA proxy for the requests Postino sends, read at startup. Lowercase names work too.

Each one does nothing when it is not set.

# Start with debug logging
$ POSTINO_LOG=debug postino

# Open the sample workspace on the local environment and log in straight away
$ POSTINO_ENV=local POSTINO_AUTOSEND=auth/login.postino postino examples/sample-workspace

On Windows, in PowerShell:

> $env:POSTINO_LOG = "debug"; & "$env:LOCALAPPDATA\Programs\Postino\postino.exe"

Not available yet

Postino has no headless mode: it cannot run a collection and print test results in a terminal or a CI pipeline. Because requests are plain files, such a runner can be built on the same file format; follow the project on GitHub for news.
