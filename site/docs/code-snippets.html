Code snippets

Turn the request you are working on into code: a curl command for a terminal or a bug report, a JavaScript fetch call or a Python requests call.

Generating a snippet

  1. Open the request.
  2. Click Code, at the right of the request editor's tabs.
  3. Pick cURL, fetch or Python.
  4. Click Copy. What is copied is exactly what the dialog shows.

What goes into the snippet

The snippet is built from what is in the editor, saved or not, resolved against the active environment and the session variables:

  • Variables and template functions are replaced. A template function such as {{ uuid() }} is evaluated once for the snippet.
  • Enabled query parameters are appended to the URL, percent-encoded.
  • Only enabled headers are included, plus the automatic Content-Type for JSON, XML and form bodies.
  • A form body is written field by field, in the style of each language.
  • Scripts are not run. Variables that only a pre-request script would set stay as {{name}} in the snippet, and so does any unknown variable.
Secrets are included

Because variables are resolved, the snippet contains the real values of tokens and passwords from your environment, including .local.env. Check it before pasting it into an issue or a chat.

Examples

For this request, with baseUrl set to https://api.example.com and token to abc123:

users/create.postino
POST {{baseUrl}}/users
Authorization: Bearer {{token}}

::: body json
{ "name": "Ada" }

cURL

One option per line. -X is left out for GET. Values are single quoted for a POSIX shell. A form body becomes one --data-urlencode per field.

curl \
  -X POST \
  'https://api.example.com/users' \
  -H 'Authorization: Bearer abc123' \
  -H 'Content-Type: application/json' \
  --data-raw '{ "name": "Ada" }'

JavaScript fetch

A form body becomes new URLSearchParams({...}).

await fetch("https://api.example.com/users", {
  method: "POST",
  headers: {
    "Authorization": "Bearer abc123",
    "Content-Type": "application/json",
  },
  body: "{ \"name\": \"Ada\" }",
});

Python requests

A form body becomes a dict passed as data.

import requests

response = requests.request(
    "POST",
    "https://api.example.com/users",
    headers={
        "Authorization": "Bearer abc123",
        "Content-Type": "application/json",
    },
    data="{ \"name\": \"Ada\" }",
)
On Windows

The cURL snippet uses POSIX shell quoting. Run it in Git Bash or WSL, or adapt the quotes for PowerShell.
