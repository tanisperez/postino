Postino documentation

Postino is a fast, native HTTP client for Linux, Windows and macOS. There is no account and no cloud: every request is a small text file that you can read, diff and commit next to your code.

Quick startOpen a folder, write your first request and send it in five minutes. InstallationInstallers, package repositories and building from source. File formatThe complete specification of .postino and .env files. Script APIEvery global available to pre-request and post-response scripts.

What Postino is

Postino is an API client in the spirit of the tools you may already know: collections on the left, the request on top, the response below. What makes it different is where your work lives.

  • A workspace is a folder. Any folder on your disk. Postino lists the requests inside it and shows its subfolders as collections.
  • A request is a file. Each request is one .postino file in a short, readable text format. Change one header and git shows you one changed line.
  • An environment is a file too. Variables live in environments/<name>.env, and secrets in a separate .local.env file that you keep out of git.
  • Nothing leaves your computer except the requests you send, and on macOS and Windows an optional update check that carries no identifiers.
users/create.postino
POST {{baseUrl}}/users
Content-Type: application/json
Authorization: Bearer {{token}}

::: body json
{ "name": "Ada Lovelace", "role": "admin" }

::: post

Platforms

Postino runs on Linux (x86_64), Windows 10 and 11 (64 bit) and macOS on Apple silicon. It is written in Rust on gpui, the GPU accelerated UI framework behind the Zed editor, so it does not bundle a web browser and stays light on memory.

License

Postino is free and open source under the Apache License 2.0. The file format is documented in the open, so your requests are never locked into the application.
