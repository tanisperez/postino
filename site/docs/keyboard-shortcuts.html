Keyboard shortcuts

Postino is built to be used from the keyboard. On macOS, use ⌘ wherever Linux and Windows use Ctrl.

General

ActionLinux and WindowsmacOS
Open the command paletteCtrl K⌘ K
Open SettingsCtrl ,⌘ ,
Show keyboard shortcutsF1⌘ Shift /
Close the tabCtrl W⌘ W
Next tabCtrl TabCtrl Tab
Previous tabCtrl Shift TabCtrl Shift Tab

Requests

ActionLinux and WindowsmacOS
Send the requestCtrl Enter⌘ Enter
SaveCtrl S⌘ S

Ctrl S also saves an environment open in the environment editor.

Environments

ActionLinux and WindowsmacOS
Select environment 1 to 9Ctrl 1 … Ctrl 9⌘ 1 … ⌘ 9
No environmentCtrl 0⌘ 0

Environments are numbered in alphabetical order, the same order as the environment picker, which shows each shortcut next to its environment.

Command palette

KeyAction
↑ ↓Move through the results
EnterOpen the request, switch to the environment or run the action
EscClose the palette

Text editing

Inputs and code editors support the usual editing keys of your platform: select all, cut, copy, paste, undo and redo, word navigation with Ctrl or Alt and the arrow keys. Right click an input for a menu with Cut, Copy, Paste and Select all. In the response body, the search button opens a find bar.

Cheat sheet

Inside Postino, press F1 (⌘ Shift / on macOS) or click the keyboard button in the status bar to see these shortcuts at any time.

Shortcuts cannot be customized yet.
