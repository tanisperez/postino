Template functions

Some values change on every send: a request id, a timestamp, a random name. Template functions produce them inline, inside {{ }}, without writing a script.

POST {{baseUrl}}/events
X-Request-Id: {{ uuid() }}
X-Sent-At: {{ isoDate() }}
Authorization: Basic {{ base64Encode("api:secret") }}

::: body json
{
  "id": "{{ uuid() }}",
  "timestamp": {{ now() }},
  "score": {{ randomInt(1, 100) }},
  "nickname": "user-{{ randomString(6) }}"
}

Each call is evaluated on its own, so {{ uuid() }} written twice gives two different UUIDs. To reuse one value in several places, generate it once in a pre-request script with vars.set("id", util.uuid()) and write {{id}} wherever you need it.

Arguments

An argument is one of:

  • A string in double quotes: "user:pass". Inside it, \" is a quote and \\ is a backslash. No other escapes exist.
  • An integer: 1, -5.
  • A variable name, without braces or quotes: base64Encode(credentials) uses the value of the variable credentials, looked up in the same layers as {{credentials}}.
GET {{baseUrl}}/search?q={{ urlEncode(searchTerm) }}
Authorization: Basic {{ base64Encode(basicCredentials) }}

Here basicCredentials holds user:password in the environment, and searchTerm may contain spaces or symbols.

Calls cannot be nested and there are no operators: {{ base64Encode(urlEncode("x")) }} and {{ randomInt(1, 10) + 1 }} are not valid. Use a pre-request script for anything more involved.

Errors

An unknown function, the wrong number of arguments, an argument of the wrong type (a string where a number is expected) or an argument that names an unknown variable all behave like an unknown variable: the whole {{ … }} marker is sent exactly as written and the response shows a warning with the reason. A template function never stops a request.

The same functions in scripts

Every function is also available in scripts as util.<name>(): util.uuid(), util.now(), util.base64Encode("text") and so on. They are the same implementation, so they behave identically and their error messages are word for word the same. In scripts, util.now() and util.randomInt() return numbers, the rest return strings. See the Script API.
