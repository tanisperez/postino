The HTTP client that keeps your requests in plain files

Postino is a fast, native API client. No account, no cloud, no telemetry. Every request is a small text file you can read, diff and commit next to your code.

Plain text, by design

One request, one file. Diffs you can actually review.

A collection is a folder and a request is a .postino file inside it. The format is short, readable and stable, so a change to a request shows up in git as the one line you changed.

  • Keep your API requests in the same repository as the API
  • Review request changes in pull requests, like any other code
  • Secrets stay out of git in a separate .local.env file
Features

Everything you need to work with HTTP APIs

A familiar layout, built for speed: collections on the left, the request on top, the response below.

Scripts and tests in JavaScript

Run a script before a request to sign it or build data, and after it to check the response and pass values on to the next one. Scripts run in a sandboxed QuickJS engine.

  • test() and expect() assertions, with results per request
  • Save a token from the login response into the environment
  • Console output captured next to the response

Load testing built in

Point a load test at a request or a whole folder, choose virtual users, duration and ramp up, and watch throughput and latency live. Every run is saved, so you can compare it with the last one.

  • Requests per second, p50, p95 and p99 latency, error rate
  • Run history stored next to your requests

Keyboard first

Press Ctrl K to jump to any request or run any action. Send with Ctrl Enter and switch environments with Ctrl 1 to 9, without touching the mouse. On macOS, use ⌘ instead of Ctrl.

Turn any request into code

Copy the request you are working on as a curl command, JavaScript fetch or Python requests call, with every variable already resolved.

Made to feel at home

Light and dark themes, or follow your system. Pick the interface and editor fonts and sizes. Postino speaks English, Spanish, Galician and Italian.
