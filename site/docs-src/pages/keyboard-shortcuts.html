Keyboard shortcuts

Postino is built to be used from the keyboard. On macOS, use ⌘ wherever Linux and Windows use Ctrl.

Requests

ActionLinux and WindowsmacOS
Send the requestCtrl Enter⌘ Enter
SaveCtrl S⌘ S
Show suggestions: variables, header names and values, script globals and membersCtrl SpaceCtrl Space
Delete the line in a script editorCtrl D⌘ Shift K
Undo the last edit of the requestCtrl Z⌘ Z
RedoCtrl Shift Z or Ctrl Y⌘ Shift Z

Ctrl S also saves an environment open in the environment editor.

Ctrl Space works in the URL, in the values of the Params, Headers and Form tables, in the fields of the Auth tab, in the header names and in the pre-request and post-response script editors, and is Ctrl on macOS too. While its menu is open, ↑ and ↓ move through the suggestions, Enter or Tab inserts the highlighted one and Esc closes it. See autocompleting variables, suggested headers and script autocompletion.

Ctrl D works only in the pre-request and post-response script editors, see editing shortcuts. On macOS it is ⌘ Shift K, because Ctrl D deletes the next character in every text field there.

Undo and redo use the request tab's own history in the URL, the table cells, the Auth fields and outside text fields; in the body, script and Docs editors they undo the editor's own typing first. See undo and redo.

Sidebar

ActionLinux and WindowsmacOS
Show or hide CollectionsAlt 1Ctrl 1
Show or hide Source ControlAlt 2Ctrl 2
Show or hide EnvironmentsAlt 3Ctrl 3
Show or hide Load testsAlt 4Ctrl 4
Rename the selected request or folderF2F2
Delete the selected request or folderDeleteDelete (Fn ⌫)
Select several requests or folders to move them togetherCtrl + click⌘ + click

The first three work anywhere in the window, even while typing, and do the same as clicking that section's button in the activity rail: the active section hides the sidebar, another one switches to it. On macOS they use Ctrl, because ⌥ with a digit types characters such as @ or # on many keyboard layouts.

Rename and Delete work while the sidebar tree has the focus, after clicking an entry, and act on that entry only. Delete asks for confirmation first. The context menu shows them next to Rename and Delete.

Environments are numbered in alphabetical order, the same order as the environment picker, which shows each shortcut next to its environment.

Load tests

ActionLinux and WindowsmacOS
Copy the results summary as MarkdownCtrl Shift C⌘ Shift C

It works while a load test tab is active and its run has finished, and does the same as Copy summary as Markdown in the Export menu: the numbers of the selected window, or of the whole run when none is selected. Copying text in an input keeps using Ctrl C (⌘ C). See load testing.

Text editing

Inputs and code editors support the usual editing keys of your platform: select all, cut, copy, paste, undo and redo (in the request editor, see undo and redo), word navigation with Ctrl or Alt and the arrow keys. Right click an input for a menu with Cut, Copy, Paste and Select all. In the response body, the search button opens a find bar.

Cheat sheet

Inside Postino, press F1 (⌘ Shift / on macOS) or click the keyboard button in the status bar to see these shortcuts at any time.

Shortcuts cannot be customized yet.
