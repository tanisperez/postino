## What changes

### Changed

- **Indent guides and a gutter line in every editor** (#303): the request body, the scripts, the Docs tab, the response body and the Code dialog draw a thin line between the line numbers and the text, and a vertical guide at each indentation level, so the fields of a nested JSON object line up at a glance. The guide of the block the cursor is in is brighter.
- **Matching XML tags** (#302): in an XML body, the name of the tag under the cursor and of its opening or closing pair are highlighted.
- **telaio 0.32.0** (#302): Postino uses the latest version of its shared design system and editor.
