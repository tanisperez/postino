Postino 0.11.0 adds context menus to the tabs and the environments, lets Linux copies installed with the install script update themselves, and fixes OAuth 2.0 with large tokens on Windows.

## What changes

### New

- **Tab menu** (#230): right click a tab for Close, Close others, Close to the right, Close to the left, Close saved and Close all, plus Copy path, Copy relative path, Show in file manager and Reveal in sidebar for requests and environments, and Rename and Duplicate for requests. The empty part of the tab bar offers New request and Close all.
- **Environment menu** (#231): right click an environment in the Environments panel to open it, use it, change its color, move it, rename, duplicate, copy its path, show it in the file manager or delete it. The empty part of the panel offers New environment.
- **Duplicate an environment** (#231): copies both its `.env` and its `.local.env`, with its color, also from the editor's More actions menu.
- **Updates from the app on Linux** (#234): a copy installed with the install script in your home folder (`~/.local`, the default) now downloads new versions and installs them on **Update ready, restart**, like on macOS and Windows, instead of asking you to run the install command again. It runs the install script that comes inside the new release, so the menu entry, the file type and the icons are updated too. The first update that installs this way is the one after 0.11.0. A script install in a system folder such as `/usr/local` keeps copying the install command, and the tarball and the AppImage keep opening the release page.
- **`--tarball` option of the install script** (#234): installs from a release tarball already on disk.

### Changed

- **Closing tabs with unsaved changes asks once** (#230): closing one or several tabs with unsaved changes, requests included, shows one dialog listing them, with Save all, Don't save and Cancel. Before, a request tab closed without asking and dropped its edits.

### Fixed

- **OAuth tokens are kept in memory only** (#228): on Windows, a request with an OAuth 2.0 profile failed after getting its token with "Value of 'password encoded as UTF-16' is longer than the platform limit of 2560 chars", because the Credential Manager cannot hold the tokens of servers such as Keycloak. Postino no longer stores tokens anywhere: they live in memory until it closes, and the first Send after opening it gets a new one (through the browser for authorization code). The entries Postino 0.10.0 left in the system credential store, under the service `postino`, are no longer used and can be deleted.
- **New workspace dialog on a short window** (#233): the `.gitignore` preview no longer runs out of the dialog and hides the Create button. The preview shrinks and scrolls with its own scrollbar, and on a very short window the rest of the form scrolls too.
