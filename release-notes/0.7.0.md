## What changes

### New

- **OpenAPI import** (#201): import OpenAPI 3.1, 3.0 and Swagger 2.0 specs, YAML or JSON, from a file, a URL or pasted text, with a three step wizard (Import menu, welcome tab, command palette or Ctrl+Shift+O). Each operation becomes a request, grouped by path segments or tags, with an environment per server, auth variables in `.local.env`, example bodies from the spec or its schemas, a status code test and docs. The preview lets you pick which requests to import.
- **OpenAPI import from a folder or a Git repository** (#202): the wizard also reads every spec of a folder and its subfolders, or of a branch of a Git repository cloned for the import, and follows the specs a Backstage `catalog-info.yaml` references. With several specs, the Options step lists them as versions to choose from, and each one gets a folder in the collection.
- **Update a collection from its OpenAPI spec** (#203): importing the same source again, or the command palette's "Update from OpenAPI: <collection>", lists what changed (added, changed with what changed, removed) and applies the chosen changes. Changed requests keep their scripts, tests, edited values and edited body. A small `.openapi.toml` in the collection folder remembers the import.
- **Git inside WSL** (#195): on Windows, a workspace kept inside WSL 2 (`\\wsl.localhost\<distro>\...`) uses the git of that distribution, through `wsl.exe`. It reads the repository on its own file system, with your Linux git configuration and SSH keys, and Git for Windows is no longer needed for it. Choosing `\\wsl.localhost\<distro>\usr\bin\git` in Settings, Git works too, and Settings shows the distribution next to the version.
- **Copy from the Console tree** (#197): click a row of the network tree to select it, then Ctrl+C (Cmd+C on macOS) copies its value, such as one header. Right click a row to copy its value, key or path. The arrow keys move through the tree and open or close branches.

### Polish

- **Console network entry** (#199): the method sits right before the URL (`GET https://...`) instead of in the column of the log lines.

### Fixes

- **Console tree with text bodies** (#196): a string with line breaks, such as a plain text body, no longer paints over the rows below it. Strings show on one row as JSON literals, with `\n` for each line break.
