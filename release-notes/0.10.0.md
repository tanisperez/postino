Postino 0.10.0 makes the Git diff faster to move through from the keyboard.

## What changes

### New

- **Step through a diff from the keyboard** (#224): the diff tab has **Prev** and **Next** buttons, `F7` and `Shift+F7` go to the next and previous block of changes, and past the last (or first) one a second press opens the next (or previous) file's diff, in the Source Control panel or in the commit. `F4` and the new **Open file** button, which replaces Open request, open the file at the current change: a request on the tab and line of the change, an environment in its editor, and any other file in its system application.
