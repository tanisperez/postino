Postino 0.10.0 brings OAuth 2.0, and makes the Git diff faster to move through from the keyboard.

## What changes

### New

- **OAuth 2.0** (#225, #226): write the OAuth settings once as a named profile of the workspace, in `.postino/project.toml`, and choose **OAuth 2.0** and the profile in a request's Auth tab. On Send, Postino gets or renews the token for the active environment: client credentials and password silently, authorization code with PKCE by signing in in your system browser. Each environment has its own token, kept in the system credential store and never in the workspace. Profile settings edit the profile inside the Auth tab, with hints about where each variable comes from and **Move to .local.env** for a secret written in clear. A token card shows the token, its claims and its expiry, the response shows **Token renewed** or the new token, the Console lists every token request with its secrets masked, and a 401 offers **Get new token and resend**.
- **OAuth 2.0 everywhere** (#227): the Postman, Bruno and OpenAPI imports create OAuth profiles from the settings they find, with their secrets in `.local.env`, instead of a fixed token. `{{ oauthToken("acme-sso") }}` puts a profile's token (or `"id_token"`) anywhere in a request. Load tests get each token once before they start and renew it when it expires.
- **Step through a diff from the keyboard** (#224): the diff tab has **Prev** and **Next** buttons, `F7` and `Shift+F7` go to the next and previous block of changes, and past the last (or first) one a second press opens the next (or previous) file's diff, in the Source Control panel or in the commit. `F4` and the new **Open file** button, which replaces Open request, open the file at the current change: a request on the tab and line of the change, an environment in its editor, and any other file in its system application.
