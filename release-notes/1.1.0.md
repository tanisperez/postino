## What changes

### Added

- **Variables built from other variables** (#301): an environment value can use other variables and add text around them, such as `usersUrl={{baseUrl}}/v2/users` or `credentials={{username}}:{{password}}`. They are expanded wherever the variable is used, through any number of steps, with session and pre-request values winning inside them too, and the tooltip in the request editor shows the expanded value. A reference that leads back to its own variable is reported as a circular reference.
- **Copy a request as a Postino command** (#297): the Code dialog has a **Postino CLI** tab, and `postino snippet --lang postino` prints the same, a `postino get`, `postino post`, ... command with every header, the `Authorization` of the Auth tab included, and the body. Paste it in a terminal to send the request without opening the window.

- **`--verbose` explains the traffic** (#299): `postino get`, `post`, ... and `postino run` take `-v` to print, like `curl -v`, the addresses a host resolved to, the connection, the TLS handshake with its version, cipher suite and the server's certificate (subject, issuer, validity, alternative names, whether it was verified), each redirect, and the headers sent and received, with secrets masked.

### Changed

- **A quieter close button in modals** (#294): the X at the top right of Settings, the environment editor, the import wizard and every other modal no longer sits on a gray square. It is a light gray X that shows its background when the pointer is over it, so the title stands out. Its tooltip shows `Esc`, which closes the modal too, and reaching it with `Tab` draws a ring around it.
- **Long modal titles wrap** (#294): a title too long for its modal continues on a second line instead of being cut.
- **Inputs that stand out** (#295): every text field, the URL bar and the sidebar filter have a stronger border, a lighter one under the pointer, and a soft accent halo while you type in them, so a field no longer gets lost on its panel.
- **A more compact find bar** (#295): in the request body, the scripts, the Docs tab and the response body, the match counter moves inside the field and **Find in selection** becomes one more toggle, `Alt+L`. The tooltips show their keys. With no match the field turns red and the arrows and the Replace buttons are disabled, and a regular expression that is not valid says what is wrong and where. The selected match has an outline, so it is easy to follow while jumping.
- **More find shortcuts** (#295): `F3` and `Shift+F3` repeat the last search with the find bar closed, `Alt+Up` and `Alt+Down` in the find and replace fields go through the searches of the session, `Ctrl+Alt+Enter` replaces every match and `Alt+P` keeps the case of each match.
- **The Windows installer asks before touching the PATH** (#298): adding Postino to the user `PATH` is now an option of the installer, checked by default. Updates keep the choice you made.

### Fixed

- **Updates install the latest version** (#300): a window left open while a newer version came out installed the update it had found at launch. Restarting to update now checks again first, and **Check for updates** replaces a downloaded update with a newer one.
- **Command line responses in the Windows console** (#296): `postino get` stopped with `cannot write: Windows stdio in console mode does not support writing non UTF-8 byte sequences` when a page was not UTF-8, such as `google.com` in ISO-8859-1. On a terminal the body is now printed as UTF-8 text, converted from its charset; piped or redirected, it is still written byte for byte.
