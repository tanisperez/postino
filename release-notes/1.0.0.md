Postino 1.0.0 is the first stable version.

## What changes

### New

- **Command line mode** (#240): the same `postino` binary now works without the window, with no display needed, for CI pipelines and servers. `postino run` runs requests, folders or the whole workspace through the same steps as Send (OAuth 2.0, scripts and `test()`), with `--env`, `--var` and `--env-file` for the variables, `--bail` and `--filter`, and readable, JSON or JUnit output. `postino get`, `post`, `put`, `patch`, `delete`, `head`, `options` and `http <METHOD>` send a one-off request like curl, with headers, query parameters, JSON, raw or multipart bodies and Basic or Bearer authorization, and `-o` downloads the body to a file with a progress bar, like wget. `postino check` validates every request and environment file. The exit codes tell a passed run from a failed test, a network error or a broken file. See the new [Running in CI](https://postino.tanis.codes/docs/ci.html) guide.
- **Load tests from the command line** (#241): `postino load` runs a load test with the app's engine and options (`--vus`, `--duration`, `--ramp-up`, `--think`, `--no-keep-alive`, `--stop-on-error`). On a terminal a live dashboard shows the progress, throughput, errors, percentiles, a latency chart, the statuses and a table per request, with `q` to stop, `p` to pause and `s` to save a report; in CI it prints progress lines. `--fail-if 'p95>500ms'` conditions set the exit code, `--report` writes the same PDF, Markdown, JSON or CSV reports as the app, the run is saved to the history unless `--no-save`, and `--compare last` prints the changes against an earlier run.
- **More commands** (#242): `postino runs` lists the saved load test runs, `runs show` and `runs compare` print one or the changes between two, and `postino report` exports a run as PDF, Markdown, JSON or CSV. `postino list` prints the request tree, `postino env` the environments and, with `--show`, their variables with secrets hidden. `postino import openapi|postman|bruno` runs the import wizard with its default choices, and `postino import curl` turns a curl command, such as a browser's "Copy as cURL", into a request. `postino snippet` prints a request as curl, `fetch` or Python, and `postino completions` prints the completion script for bash, zsh, fish or PowerShell.
- **Context menus from the keyboard** (#232): `Shift+F10`, or the menu key on Linux and Windows, opens the menu of the active tab under it, or, while the Environments panel is shown, the menu of the environment open in the active tab. The arrow keys, Enter and Esc work in it.

### Changed

- **Faster git for workspaces inside WSL** (#229): git commands no longer start `wsl.exe` each. Postino keeps one running and sends the commands to it, so only the first command waits for it to start. Set `TELAIO_GIT_WSL_SESSION=0` to go back to the old way.

- **New look for the dialogs** (#237): every dialog, from Settings to the confirmations, is a flat panel with a solid border, a short shadow and a darker backdrop. The header has no dividing line and shows an icon before the title, and the close button sits on a light background. A destructive confirmation shows a warning icon in red.
- **Updated libraries** (#243): the UI toolkit moves to gpui-kit 0.9.1, and the other dependencies to their latest compatible versions.
- **A lighter response viewer** (#258, #151): the response body uses the text editor of ted, which draws only the visible lines. A 15 MB JSON response now takes about 56 MB of memory instead of about 460 MB, and scrolls smoothly. Point at the line numbers to fold a JSON object or array, `Ctrl+F` in the body opens the find bar (case, whole word, regular expression, find in selection), and `Alt+Z` wraps long lines. A body whose shown text is over 4 MB is shown without colors. The Code dialog uses the same editor.
- **One style of right-click menu for text** (#264): every text field (the URL, headers, parameters, filters, the OAuth fields, the load test search) opens the same menu as tabs and environments, on Linux, Windows and macOS, in the language of the interface. It adds **Undo** and **Redo** to **Cut**, **Copy**, **Paste** and **Select all**. Fields that had no menu, such as the load test search, now have one.
- **Keyboard hints in the command palette** (#237): a bar at the bottom shows the keys to move, open and close. The search field is larger.
- **Filter in the keyboard shortcuts cheat sheet** (#237): type part of an action or of its keys to list only the shortcuts that match. The keys are drawn as key caps, and the up and down arrows scroll the list.

### Fixed

- **Commit buttons of the same width** (#238): in Source Control, **Commit** and **Commit and Push…** now have the same width. They share the row when the panel is wide enough and stack, each at full width, when it is narrow, so the second label is never cut.
- **Names starting with a dot** (#246): a request, folder or environment named with a leading dot, such as `.draft` or `../old`, was saved as a hidden file and vanished from the sidebar. Leading dots are now removed from the name, like trailing ones.
- **Load test error cleared on a new target** (#247): after pressing Start with no request or folder chosen, picking one now removes the error and the failed mark of the run in the panel.
- **No "No response body" after a failed send** (#249): when a request fails before any response comes back, the Body tab shows only the error, not a note about a body that was never received.
- **Translated TLS certificate warning** (#250): the warning shown when a request was sent with an invalid certificate is now in the language of the interface. The reason, such as `certificate expired`, stays as the TLS library writes it.
- **Import shortcut label** (#251): the keyboard shortcuts sheet now names Ctrl+Shift+O "Import OpenAPI, Postman or Bruno", as the welcome page does.
- **New tab fully in view** (#248): a tab opened just when the tab bar starts to overflow is no longer cut by the scroll arrows.
- **Sidebar rows** (#252): a long request or folder name ends in an ellipsis instead of being cut at the panel's edge, and a row darkens while it is pressed.
- **Scrolling the load test results** (#253): the mouse wheel keeps scrolling the results when the pointer passes over the Per request table, instead of sliding the table sideways. Shift and the wheel, or its scrollbar, still scroll the table sideways when it is wider than the panel.
- **Load test Start errors** (#254): when Start cannot begin a run, because no request or folder is chosen, the folder is empty or a request cannot be read, Postino only shows why. The run is no longer marked as failed in the panel, and the results of an earlier run keep their state.
- **Import wizard header** (#255): the import wizard has the same header as every other dialog: an icon, the title and a small close button.
- **Code dialog** (#256): the snippet is highlighted like the request editor, and the dialog keeps one height for cURL, fetch and Python. **Copy** is a labeled button next to the languages and says **Copied** for a moment; the arrow keys change the language and Ctrl+C copies the whole snippet. A JSON body is written as an object in `JSON.stringify(...)` for fetch and as `json=` with a `dict` for Python, also in `postino snippet`.
- **Environment variables table** (#259, #257): the header stays in place while the variables scroll, inside the table's border, with a scrollbar that does not cover the delete buttons.
- **Load test target picker** (#260): choosing the request or folder of a load test opens a menu with a search field, the requests grouped by folder with their method, or the folders with their number of requests. It stays inside the window and scrolls, and the box shows the method, name and folder of the request chosen.
- **URL with an undefined variable** (#261): a URL that starts with a variable with no value, such as `{{baseUrl}}/users` with no environment, no longer gets `http://` in front of it in the Code dialog, `postino snippet` and the console.
- **Environments panel footer** (#262): on a narrow panel the `environments/` folder name ends in an ellipsis and the **Show** button stays whole.
- **Launcher spacing** (#263): with a workspace open and no tabs, the workspace name starts a little higher, as the welcome tab does next to the sidebar.
- **Thousands with a dot** (#244): in Spanish, Galician and Italian, numbers group their thousands with a dot from four digits on, `1.234` and `17.304`. Galician had moved to a space with the updated Unicode data, and four digit numbers had no separator in Spanish and Italian.
- **API key name** (#270): a new API key auth starts with `X-API-Key` as its name. The field showed it only as a hint, so it looked filled while it was empty and the request went without the key.
- **Authentication in code snippets** (#269): with OAuth 2.0, the Code dialog and `postino snippet` now include the token, in the header or query parameter of the profile: the one Postino holds for the active environment, or `<access token>` when there is none. Basic, Bearer and API key auth were already included.
