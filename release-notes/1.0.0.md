Postino 1.0.0 is the first stable version.

## What changes

### New

- **Context menus from the keyboard** (#232): `Shift+F10`, or the menu key on Linux and Windows, opens the menu of the active tab under it, or, while the Environments panel is shown, the menu of the environment open in the active tab. The arrow keys, Enter and Esc work in it.

### Changed

- **Faster git for workspaces inside WSL** (#229): git commands no longer start `wsl.exe` each. Postino keeps one running and sends the commands to it, so only the first command waits for it to start. Set `TELAIO_GIT_WSL_SESSION=0` to go back to the old way.

- **New look for the dialogs** (#237): every dialog, from Settings to the confirmations, is a flat panel with a solid border, a short shadow and a darker backdrop. The header has no dividing line and shows an icon before the title, and the close button sits on a light background. A destructive confirmation shows a warning icon in red.
- **Keyboard hints in the command palette** (#237): a bar at the bottom shows the keys to move, open and close. The search field is larger.
- **Filter in the keyboard shortcuts cheat sheet** (#237): type part of an action or of its keys to list only the shortcuts that match. The keys are drawn as key caps, and the up and down arrows scroll the list.

### Fixed

- **Commit buttons of the same width** (#238): in Source Control, **Commit** and **Commit and Push…** now have the same width. They share the row when the panel is wide enough and stack, each at full width, when it is narrow, so the second label is never cut.
